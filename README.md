# p-1
تمرین مباحث ویژه جلسه 1 

موضوع پروژه: طراحی جدول برنامه هفتگی با استفاده از HTML و CSS

توضیحات:

در این پروژه یک صفحه وب ساده برای نمایش برنامه هفتگی دانشجو طراحی شده است. در این صفحه از زبان HTML برای ایجاد ساختار صفحه و ساخت جدول استفاده شده و با استفاده از CSS، ظاهر صفحه زیباتر و منظم‌تر شده است.

جدول شامل چهار ستون روز، درس، ساعت و لینک آموزش است و پنج درس مختلف را نمایش می‌دهد. برای هر درس یک لینک به سایت آموزشی مرتبط قرار داده شده است.

در بخش CSS، رنگ پس‌زمینه صفحه، رنگ عنوان جدول، حاشیه سلول‌ها، فاصله داخلی و نحوه قرارگیری جدول تنظیم شده است. همچنین با استفاده از ویژگی hover، هنگام قرار گرفتن نشانگر ماوس روی ردیف‌های جدول یا لینک‌ها، ظاهر آن‌ها تغییر می‌کند.

در انتهای صفحه نیز یک لینک داخلی قرار داده شده است که با کلیک روی آن، کاربر به ابتدای صفحه بازمی‌گردد.

تگ‌ها و ویژگی‌های استفاده‌شده:

table برای ساخت جدول

tr برای ایجاد ردیف‌های جدول

th برای عنوان ستون‌ها

td برای نمایش اطلاعات هر سلول

a برای ایجاد لینک‌های خارجی و داخلی

style برای نوشتن کدهای CSS داخل فایل HTML

id برای مشخص کردن مقصد لینک داخلی

border-collapse برای یکپارچه کردن خطوط جدول

margin و padding برای تنظیم فاصله‌ها

hover برای تغییر ظاهر عناصر هنگام قرار گرفتن نشانگر ماوس روی آن‌ها

هدف پروژه:

هدف از انجام این تمرین، آشنایی مقدماتی با ساخت جدول در HTML، ایجاد لینک‌های مختلف و استفاده از CSS داخلی برای طراحی و زیباسازی یک صفحه وب است.
